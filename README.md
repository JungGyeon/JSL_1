# 🎬 ANIVERSE

### 애니메이션을 검색하고, 즐겨찾기하고, 나만의 취향에 맞는 작품을 추천받을 수 있는 웹 서비스

<br>

## 📖 About

**ANIVERSE**는 애니메이션을 보다 편리하게 탐색하고,
관심 있는 작품을 관리할 수 있도록 제작한 애니메이션 추천 웹 서비스입니다.

애니메이션 검색부터 상세 정보 확인, 즐겨찾기,
그리고 즐겨찾기한 작품의 태그를 기반으로 한 추천 기능을 제공합니다.

<br>

## 📅 Development Period

**2026.7.30 ～ 2026.9.20**

<br>

## ✨ Features

### 🔎 Anime Search
애니메이션의 제목을 검색하고 작품의 상세 정보를 확인할 수 있습니다.

### ❤️ Favorite
관심 있는 애니메이션을 즐겨찾기에 등록하고 한눈에 관리할 수 있습니다.

### 💡 Recommendation
즐겨찾기한 애니메이션의 태그를 분석하여
취향과 유사한 애니메이션을 추천합니다.

### 👤 Member
회원가입과 로그인 기능을 통해 개인별 즐겨찾기 및 추천 서비스를 제공합니다.

### 🌓 Theme
Light / Dark 모드를 지원하여 원하는 화면 테마를 선택할 수 있습니다.
