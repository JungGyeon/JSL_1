# 🎬 ANIVERSE

### アニメを検索し、お気に入り登録し、自分の好みに合った作品をおすすめしてもらえるWebサービス

<br>

## 📖 About

**ANIVERSE**は、アニメをより便利に探し、
気になる作品を管理できるように制作したアニメ推薦Webサービスです。

アニメの検索から詳細情報の確認、お気に入り登録、
そしてお気に入り作品のタグをもとにしたおすすめ機能を提供します。

<br>

## 📅 Development Period

**2026.7.30 ～ 2026.9.20**

<br>

## ✨ Features

### 🔎 Anime Search
アニメのタイトルを検索し、作品の詳細情報を確認できます。

### ❤️ Favorite
気になるアニメをお気に入りに登録し、まとめて管理できます。

### 💡 Recommendation
お気に入り登録したアニメのタグを分析し、
好みに合ったアニメをおすすめします。

### 👤 Member
会員登録とログイン機能により、ユーザーごとにお気に入りやおすすめ機能を利用できます。

### 🌓 Theme
Light / Darkモードに対応し、好みに合わせて画面テーマを選択できます。
