Project Overview

プロジェクト概要 개요

01 · Overview

開発背景

Background

  • Servlet/JSP 実務理解 — フレームワークに頼らず、HTTPリクエスト・レスポンスとセッション管理の原理を直接実装して体得

  • 好きなテーマで開発 — アニメというテーマで、検索・推薦・コミュニティを一つのサービスに統合

開発目的

Objectives

  • CRUD の完全実装 — 生成・照会・修正・削除の全ライフサイクルを実装

  • MVC パターンの徹底 — Controller / Service / DAO を分離し保守性を確保

  • DB 設計力の証明 — 7つのテーブルの正規化とリレーション設計

プロジェクト範囲

Scope

  • コア機能：会員登録・ログイン・掲示板・コメント・お気に入り

  • 応用機能：OAuth連携、メール認証、パスワード暗号化、タグ推薦、ダーク/ライトモード

成果

Key Results

  • 開発期間（2026.7.30～2026.9.20） で計画した全機能(MVP)を実装完了

  • UIの完成度 — ダーク/ライトモード双方に対応したテーマ設計まで仕上げ

Tech Stack

技術スタック 기술 스택

02 · Tech Stack

フレームワークに頼らない Java Servlet ベースのバックエンドと Oracle Database を組み合わせ、実務に近い堅牢な Web アプリケーション環境を構築した。

Frontend

View Layer

  • JSP / JSTL条件分岐・反復タグでロジックレス表示
  • CSS 変数ダーク/ライト テーマ トークン設計
  • JavaScriptVanilla JS によるクライアント側ページネーション

Backend

Control / Logic

  • Servletコマンドパターンでパス分岐・ディスパッチ
  • JDBCDriverManager 直結（コネクションプール不使用）
  • jBCryptパスワードのハッシュ化・検証

Database

Persistence

  • Oracle XEthin ドライバ / SQL Developer で運用
  • PreparedStatement全クエリをパラメータ化し SQL Injection を防止
  • ROWNUM / MERGEサーバー側ページング・リアクション upsert

Server & Tools

Environment

  • TomcatApache Tomcat 上で Dynamic Web Project として稼働
  • EclipseIDE / Eclipse Dynamic Web Project 構成
  • Bootstrap 5.3.3CDN 読み込み + 独自 CSS 変数でテーマ拡張

Why Servlet & JSP?

Spring のような自動化された機能に頼るのではなく、Webアプリケーションの動作原理（Request / Response、Session など）を深く理解するために、素の Servlet / JSP を選択した。

Core Feature 01

アニメ検索・お気に入り・推薦 애니 검색/즐겨찾기/추천

06 · Features

検索・一覧表示

Search & Listing

1. キーワード検索

TITLE 列を対象に部分一致検索を実行

WHERE title LIKE '%鬼滅%'

2. 人気ランキング

FAVORITE の件数を集計して人気順に並び替え

3. カードグリッドのページネーション

ビューポート幅から列数（2 / 3 / 4列）を判定し、常に3行分だけを表示

2列（〜767px） 3列（768px〜） 4列（992px〜）

お気に入り & タグ推薦

Favorite & Recommend

1. お気に入り登録・解除

FAVORITE テーブルへの INSERT / DELETE で即時反映

2. タグベースの推薦アルゴリズム

お気に入り作品と共通タグを多く持つ未お気に入り作品を抽出

ORDER BY match_count DESC, score DESC

3. マイページ連携

お気に入り一覧をマイページに表示し、推薦の入力データとして再利用

Core Feature 02

掲示板・コメント 게시판/댓글

07 · Features

掲示板機能

Board

1. CRUD の実装

作成・照会・修正・削除（本人の投稿のみ修正／削除可）

2. サーバー側ページング

Oracle の ROWNUM を使い、必要な範囲だけを取得

WHERE rnum BETWEEN ? AND ?

3. 検索・閲覧数

タイトル/本文/作成者で検索し、詳細表示のたびに閲覧数を加算

4. いいね／よくないね

BOARD_REACTION を MERGE 文で upsert し、1ユーザー1状態を維持

MERGE INTO board_reaction USING dual ...

コメント機能

Comment

1. コメント登録

投稿詳細ページから即時に登録・DB保存

INSERT INTO board_comment ...

2. コメント一覧照会

BOARD_ID を外部キーとして関連コメントを取得

BOARD
PK: BOARD_ID
COMMENT
FK: BOARD_ID

3. 権限チェック

セッションのログインユーザーとコメント作成者を照合

4. 連鎖削除

投稿削除時に該当コメントを一括削除し整合性を保持

Core Feature 03

会員・認証・UIテーマ 회원/인증/UI 테마

08 · Features

会員・認証

Member & Auth

1. パスワード暗号化

登録時に jBCrypt でハッシュ化し、照合時も同ロジックで検証

password = BCrypt.hashpw(pw, BCrypt.gensalt())

2. セッションログイン

HttpSession に userid / nickname を保持し、ページ側で表示を分岐

3. メールアドレス認証

認証コードを送信・照合して本人確認を実施

MailSender / MailConfig

4. ソーシャルログイン（OAuth）

Google / Line アカウントでの連携ログインに対応

Google OAuth Line OAuth

ダーク／ライトモード UI

Theme Tokens

CSS カスタムプロパティ（--bg / --surface / --text / --accent 等）を body.light-mode の有無で丸ごと切り替え、全ページに一括反映する。

Light light-mode
Dark default

WCAG コントラスト比を検証し、両モードともテキストが十分な可読性を確保するよう調整済み。
